# Sprint 001 — Flight

## Objective

> Make Lunaris fly.

## Tasks

### AOTS-001 — Project bootstrap

Create the repository foundation, canonical documentation, Godot project, test environment, placeholder Lunaris, semantic input actions, and debug HUD.

### AOTS-002 — Lunaris Flight Controller

Implement and iterate on Lunaris's foundational three-dimensional flight movement.

### AOTS-003 — Third-Person Flight Camera

Create a camera that supports readable, comfortable flight.

### AOTS-004 — Acceleration / Speed / Boost

Add speed control, acceleration behaviour, and boost.

### AOTS-005 — Flight telemetry

Connect live speed, altitude, flight state, and performance data to the debug HUD.

### AOTS-006 — Flight test environment improvements

Improve spatial references and traversal situations in response to flight testing.

### AOTS-007 — Flight-feel iteration

Tune movement and camera behaviour through repeated playtesting.

## Completion condition

A tester can freely fly Lunaris around a simple environment for five minutes, and the movement is enjoyable enough to justify continued development.

Do not start combat during Sprint 001.
